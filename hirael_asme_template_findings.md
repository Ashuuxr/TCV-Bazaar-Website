# Hirael Asme template findings

Source: https://21st.dev/@mohammadshehadeh/templates/hirael-asme
Preview: https://hirael.com/embed/templates/asme

The template is a dark, liquid-glass marketing landing page. Its strongest patterns are a full-viewport cinematic hero, a thin frosted-glass pill navigation, an oversized editorial serif headline with italic emphasis, compact inline email/CTA treatment, and a strong single visual backdrop. The preview uses a dark cosmic image/video field with high contrast white type and restrained outlined controls.

The page then transitions into scroll-revealed editorial sections: About Us, an approach statement, an Innovation × Vision split, services, and a multi-column footer. Navigation is intentionally short and focused rather than exposing every page in the first row. The template is MIT-licensed according to the catalog page, but this project will adapt the layout language and interaction patterns to TCV Bazaar’s own brand, copy, assets, and booking conversion flow rather than copy unrelated content.

Applicable TCV Bazaar adaptation: retain the current event video as the cinematic hero, use a frosted pill navigation treatment, keep the gold/ivory TCV palette instead of Asme’s dark blue cosmic palette, use the existing booking and stall-layout CTAs instead of a newsletter form, and organize the current About / Why Exhibit / Packages / Stall Layout / Gallery / Testimonials content into a calmer editorial scroll rhythm.
